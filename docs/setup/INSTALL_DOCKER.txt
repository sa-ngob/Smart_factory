คู่มือการติดตั้งและใช้งาน Smart Factory (Docker Version)
======================================================

เอกสารนี้จะอธิบายขั้นตอนการนำระบบ Smart Factory ไปติดตั้งและใช้งานบนเครื่อง Server หรือ PC เครื่องอื่น
โดยใช้เทคโนโลยี Docker ซึ่งจะช่วยให้ไม่ต้องติดตั้ง Node.js หรือ Python แยกในเครื่องนั้นๆ

1. สิ่งที่ต้องเตรียม (Prerequisites)
------------------------------------------------------
ก่อนเริ่มติดตั้ง ให้แน่ใจว่าเครื่องเป้าหมายได้ทำการติดตั้งโปรแกรมเหล่านี้แล้ว:

1.  **Docker Desktop** (สำหรับ Windows/Mac) หรือ **Docker Engine** (สำหรับ Linux)
    *   ดาวน์โหลดได้ที่: https://www.docker.com/products/docker-desktop/

2.  เตรียมไฟล์โปรเจกต์ (Source Code)
    *   Copy โฟลเดอร์โปรเจกต์นี้ทั้งโฟลเดอร์ ไปวางไว้ที่เครื่องเป้าหมาย (เช่น `C:\App\SmartFactory` หรือ `/home/user/SmartFactory`)

------------------------------------------------------

2. ขั้นตอนการติดตั้งและรันโปรแกรม (Installation & Run)
------------------------------------------------------
1.  เปิดโปรแกรม **Terminal** (Mac/Linux) หรือ **PowerShell / Command Prompt** (Windows)

2.  Change Directory (cd) เข้าไปยังโฟลเดอร์ที่เก็บไฟล์โปรเจกต์
    ตัวอย่าง:
    cd C:\App\SmartFactory
    
3.  รันคำสั่งเพื่อสร้างและเริ่มทำงานระบบ (Build & Start)
    
    docker-compose up --build -d

    *   `--build` : สั่งให้สร้าง Image ใหม่ทุกครั้ง (แนะนำให้ใส่ในครั้งแรก หรือเมื่อมีการแก้โค้ด)
    *   `-d`      : (Detached mode) สั่งให้ทำงานเบื้องหลัง ไม่ต้องเปิดหน้าต่างค้างไว้

4.  รอจนกว่าระบบจะทำงานเสร็จ (ขึ้นสถานะ Done/Created ทั้ง 3 services: postgres, web, plc)

------------------------------------------------------

3. การเข้าใช้งาน (Accessing the Application)
------------------------------------------------------
เมื่อรันเสร็จเรียบร้อยแล้ว สามารถเข้าใช้งานผ่าน Web Browser (Chrome, Edge) ได้ดังนี้:

*   **เข้าใช้งานจากเครื่องที่ติดตั้ง (Local Machine):**
    http://localhost:3000

*   **เข้าใช้งานจากเครื่องอื่นในวงแลน (LAN):**
    http://<A_IP_ADDRESS>:3000
    (เช่น http://192.168.1.50:3000)

------------------------------------------------------

4. คำสั่งจัดการที่ใช้บ่อย (Common Commands)
------------------------------------------------------
ให้รันคำสั่งเหล่านี้ใน Terminal ภายในโฟลเดอร์โปรเจกต์

*   **หยุดการทำงานของระบบ:**
    docker-compose down

*   **ดูสถานะการทำงาน (ดูว่า Container ไหนรันอยู่บ้าง):**
    docker-compose ps

*   **ดู Logs ของระบบ (เพื่อตรวจสอบ Error):**
    docker-compose logs -f
    (กด Ctrl + C เพื่อออกจากหน้านี้)

*   **ดู Logs เฉพาะส่วน (เช่น Web, Python, Database):**
    docker-compose logs -f web
    docker-compose logs -f plc
    docker-compose logs -f postgres

------------------------------------------------------

5. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)
------------------------------------------------------
*   **Database connection error:**
    *   อาจเกิดจาก Database ยัง Start ไม่เสร็จ ให้รอสักครู่ (ประมาณ 1-2 นาที) แล้วลอง Refresh หน้าเว็บ
    *   ตรวจสอบว่า Port 5433 ในเครื่องว่างอยู่หรือไม่ (Docker จะใช้ Port นี้สำหรับ Database ภายนอก)

*   **เข้าเว็บไม่ได้ (Site can't be reached):**
    *   ตรวจสอบ Firewall ของเครื่อง Server ว่าอนุญาต Port 3000 หรือไม่
    *   ลองรันคำสั่ง `docker-compose ps` ดูว่าสถานะเป็น Up หรือไม่
